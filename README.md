# Finars Studio

Sodobna spletna stran arhitekturnega biroja **FIN ARS d.o.o.** (Zagorje ob Savi).

## O projektu

- Dizajn v stilu Apple / sofisticiranih arhitekturnih birojev
- Responsive (mobile + desktop)
- Animirano arhitekturno ozadje
- Lightbox / zoom na slikah projektov
- Strani: Domov, Projekti, O nas, Storitve, Kontakt

## Projekti

Vključeni so projekti z originalne strani www.finars.si:
Hiša v gozdu, Olimpijski bazen Libija, Hotelski center Tripoli, Šola Trbovlje, Mladinski center Trbovlje, Urbana dnevna soba, ČZS, Stanovanja R, Vrtec Kisovec, Mercator Škofja Loka, SPAR Litija, Blok K3 Celje, Podčetrtek, Avtohiša Sallaumines in drugi.

## Zaganjaj lokalno

Odpri `index.html` v brskalniku ali uporabi lokalni strežnik:

```bash
npx serve .
```
